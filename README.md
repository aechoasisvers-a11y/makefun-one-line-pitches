A one-sentence pitch for make.fun's "A Day of One-Line Pitches" bounty: it invites a friend who has never coded to describe their app idea in plain words and let an AI agent build a working version of it on make.fun. The program writes the pitch to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
